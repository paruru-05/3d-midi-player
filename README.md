# 3D MIDI Player

MIDIファイルを読み込み、3D空間で演奏を可視化するブラウザベースのMIDIプレイヤーです。

**デモ:** https://paruru-05.github.io/3d-midi-player/

## 機能

- MIDIファイルのドラッグ＆ドロップ / ファイル選択
- 4つの可視化ビュー
  - Fall
  - PianoRoll 3D
  - TopDown
  - Keyboard 3D
- PianoRoll 3D / TopDownでは、曲の音域に合わせた3Dピアノ鍵盤を表示
- プレイヘッドでノートをクリップし、視点位置によるノートの貫通を防止
- 再生 / 一時停止 / 停止、シーク、再生速度、マスター音量
- トラックごとのミュート / ソロ / 音量調整
- ノートの色モード（トラック / チャンネル / ベロシティ / 音階）
- ノートの幅W・高さHを個別に調整（時間方向の長さはノート長のまま）
- ノート移動速度を0.2〜12で調整（再生速度とは独立）
- 発音中ノート（開始 ≦ 現在時刻 < 終了）の発光
  - ON/OFF、強度、パルス・残光付き
  - 停止・シーク・ビュー切替時にリセット
- 全ビューのプレイヘッドエフェクト
  - 火花・パーティクル / 上昇する光の筋 / リング・フラッシュ
  - 全体ON/OFFと種類別ON/OFF、強度・サイズ・継続時間・同時上限数
  - 固定プールによる描画で、クリッピング面を貫通しない
- 3灯ライティング
  - 環境光 / キーライト / リムライト
  - 各ライトのON/OFF・強度・色、キー/リムは方位・仰角も調整可能（影なし）
- 空間の背景色をカラーピッカーで変更（フォグ色と連動、ドーム表示時は画像を優先）
- 背景画像をプラネタリウム風の半球ドームに表示
  - 静止画に加えGIF・MP4・WebMに対応（動画はミュート・ループ・自動再生）
  - 視点追従ON/OFF（ONはカメラの位置と向きの両方に追従）
  - 不透明度、半径、高さ、回転、スピンを調整可能
- Fallの壁（プレイヘッド面）設定
  - 透明度・色・静止画画像（画像と色は併用、画像なし時は色＋透明度）
- カメラ操作
  - 左ドラッグで回転、右ドラッグでパン、ホイールでズーム
  - WASD / 矢印キーで移動、トップバーの「視点リセット」で初期位置へ
  - 移動範囲はシーンが破綻しないよう制限
- 全画面表示
  - トップバーの「全画面」ボタン、またはFキーで切替（ESCで解除）
  - 左右UIを含むアプリ全体を全画面化し、canvas・カメラアスペクトを再計算
- ロード中のUX
  - MIDI・音源の読み込み中は3Dステージに半透明の白オーバーレイ＋ローディング表示
  - カメラ操作を禁止し、再生ボタンを無効化（GUIは操作可能）
  - 完了・失敗時に復帰。読み込み中に別ファイルを選んだ場合は最新のファイルを優先
- カスタムSF2 / SF3サウンドフォントの読み込み

## 使い方

1. デモページを開きます。
2. 「ファイルを開く」からMIDIファイル（`.mid` / `.midi`）を選択するか、画面へドラッグ＆ドロップします。
3. ビューやパラメータを変更して再生します。

デフォルトのGM音源はCDNから読み込まれるため、初回再生時はインターネット接続が必要です。カスタムSF2 / SF3を読み込むと、ローカルの音源で再生できます。

### カメラ操作

| 操作 | 動作 |
| --- | --- |
| 左ドラッグ | 回転 |
| 右ドラッグ | 平行移動（パン） |
| ホイール | ズーム |
| WASD / 矢印キー | 前後左右・上下移動 |
| 「視点リセット」ボタン | 現在のビューの初期カメラ位置へ戻す |
| Fキー / 「全画面」ボタン | 全画面の切替 |
| ESC | 全画面の解除 |

### 背景ドーム

- 「画像/GIF/動画を読み込む」から静止画・GIF・MP4・WebMを選択できます。
- 動画はミュート・ループ・自動再生・インライン再生でドームに投影されます。
- 読み込みに失敗した場合は既存の背景を維持します。
- 視点追従ONではカメラの位置と向きに追従し、回転・スピン・半径・高さは加算されます。

### Fallの壁

- 透明度（0〜1）と色を設定できます。
- 静止画を読み込むと色と併用して表示され、解除すると色＋透明度の表示に戻ります。
- 画像の差し替え・解除時は古いテクスチャを破棄します。

## 開発

### 必要な環境

- Node.js 20.19以上（推奨: 22.12以上）
- npm

### セットアップ

```bash
npm install
```

### 開発サーバー

```bash
npm run dev
```

### 本番ビルド

```bash
npm run build
```

`dist/`に静的ファイルが出力されます。

### ビルドのプレビュー

```bash
npm run preview
```

## GitHub Pages

`main`ブランチへのpush時にGitHub Actionsが自動でビルドし、GitHub Pagesへデプロイします。

- ワークフロー: `.github/workflows/deploy.yml`
- 公開URL: https://paruru-05.github.io/3d-midi-player/

Viteの`base`は`./`に設定しているため、プロジェクトページ配下でもアセットを解決できます。

## 構成

```text
src/
  app/        アプリケーションUIと状態管理
  audio/      Web Audio / サンプラー
  midi/       MIDI読み込みとGM音源名
  playback/   再生トランスポート
  state/      型定義
  visual/     Three.jsシーン、ビュー、鍵盤、エフェクト
public/       ファビコン
index.html    アプリシェル
```

## 補足

- リポジトリにはMIDIファイルやサウンドフォントを含みません。
- `node_modules/`、`dist/`、ローカルのサウンドフォント（`.sf2` / `.sf3`）は`.gitignore`で除外しています。
- パラメータ設定の永続化（リロード後の保持）は対象外です。
- WebGLとWeb Audio APIに対応したモダンブラウザで利用してください。
